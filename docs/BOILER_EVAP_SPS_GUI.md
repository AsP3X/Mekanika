# Boiler, Thermal Evaporation, and SPS GUIs

## Thermoelectric Boiler
- Steam production rate and heat input.
- Coolant and superheating status.
- Pressure and temperature gauges.
- Port configuration.
- Formation status.

## Thermal Evaporation Plant
- Brine input and lithium (or other) output rates.
- Height and solar panel status.
- Valve configuration.
- Efficiency based on structure height.

## Supercritical Phase Shifter (SPS)
- Chemical input/output rates.
- Energy consumption.
- Internal component status.
- Port and valve configuration.

## Shared Patterns
- Integrate Multiblock Data panel.
- Clear formation and failure feedback.
- Side configuration for ports.
- Debug tool reports key rates.
