# Ore Processing Chain (2× to 5×)

## Goals
- Progressive ore multiplication with increasing complexity.
- Clear chemical and machine requirements at each tier.

## Stages
1. **2×** — Enrichment Chamber → Crushed Ore → Smelter.
2. **3×** — Purification Chamber + Chemical Injection Chamber.
3. **4×** — Chemical Dissolution Chamber + Chemical Washer.
4. **5×** — Chemical Crystallizer + final smelting.

## Chemicals Involved
- Hydrogen Chloride, Sulfuric Acid, Oxygen, etc.
- Ratios are data-driven.

## Machine Roles
- Each stage uses a dedicated machine or factory variant.
- Factories support parallel processing of the same recipe.
- Side configuration for chemical and item input/output.
