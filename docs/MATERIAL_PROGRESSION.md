# Ore and Material Progression

## Goals
- Clear early-game path from ores to alloys and basic machines.

## Stages
- Ore generation (Osmium-style).
- Smelting and enrichment.
- Alloy production (Infuser).
- Basic machine crafting.
- Progression into chemical processing.
