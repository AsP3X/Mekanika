# Localization Conventions

## Goals
- Consistent naming and message keys.

## Conventions
- Block and item names: mekanika.block.*, mekanika.item.*
- GUI titles and tooltips.
- Failure and status messages.
- JEI/EMI category names.

## Notes
- Use translation keys for all player-facing text.
- Document key structure for translators.
- Support for multiple languages.
