# Multiblock Data GUI

Pixel positions, screen sizes, and required widgets are in [GUI_LAYOUTS.md](GUI_LAYOUTS.md).

There is no separate data screen and no debug tab. Each structure screen includes the text panel defined in the layout doc. That panel shows the formed flag and the counts named for that structure. The last formation failure stays on the chat line from [MULTIBLOCK_STRUCTURES.md](MULTIBLOCK_STRUCTURES.md).
