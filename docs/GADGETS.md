# Gadgets

## Goals
- Utility items that support industrial gameplay without replacing core systems.

## Examples
- Atomic Disassembler: Tiered mining tool with modes.
- Free Runners: Movement speed enhancement.
- Jetpack or similar flight aid (energy-consuming).
- Configurator: Multi-mode tool for side configuration and wrenching (covered in Control System).

## Integration
- Energy consumption where applicable, using the shared energy system.
- Optional module compatibility with MekaSuit.
- Data-driven stats and modes.
- Debug tool can report energy status on gadgets.

## Notes
- Keep gadgets focused and balanced.
- Prefer energy costs over durability where it fits the theme.
- Document crafting and progression placement.
