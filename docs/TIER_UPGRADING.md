# Tier Upgrading

## Goals
- Allow machines to be upgraded from Basic to Ultimate in-world or via crafting.

## Methods
- Tier Installer item or machine.
- Right-click with installer on compatible machine.
- Preserves contents and configuration where practical.
- Data-driven upgrade requirements.

## Notes
- Factories upgrade slot count with tier.
- Clear feedback on success or missing materials.
- Config cards remain compatible after upgrade.
