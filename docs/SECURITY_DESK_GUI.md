# Security Desk GUI

## Goals
- Manage ownership and trusted player lists.
- Apply security modes to machines, tanks, QIO, and multiblocks.

## Layout
- Current owner display.
- Trusted player list with add/remove.
- Security mode selector (Public / Private / Trusted).
- Apply to nearby or selected machines.
- Config card integration for copying security settings.

## Interaction
- Add players by name or from nearby.
- Clear feedback on access changes.
- Works in multiplayer.

## Integration
- Shared security system from Control System.
- Multiblock controllers inherit security.
- Debug tool reports owner and mode.
