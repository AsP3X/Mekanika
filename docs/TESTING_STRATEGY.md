# Testing Strategy

## Unit Tests
- Validators with synthetic structures.
- Tank insert/extract with simulation.
- Network merge/split logic.

## Integration / Manual
- Formation and invalidation of small and max-size structures.
- Ore processing chain correctness.
- Energy and chemical network throughput under load.
- Config card copy/paste edge cases.
- Radiation exposure and protection.

## Regression
- Add tests for any fixed formation or network bugs.
