# GUI Patterns

## Shared Conventions
- Consistent slot layouts for machines and factories.
- Progress bars with clear direction.
- Side configuration widget with color language.
- Energy and chemical/fluid tank displays.
- Redstone and security indicators.

## Machine GUIs
- Input slots left, output slots right, processing area center.
- Upgrade slots in a dedicated area.
- Config button or Configurator integration.

## Factory GUIs
- Multiple process slots with shared progress visualization.
- Auto-sort toggle.
- Slot count scales with tier.

## Multiblock GUIs
- Opened from any structural block via controller.
- Aggregated stats displayed prominently.
- Port configuration accessible.

## Notes
- Use vanilla-style widgets where possible for familiarity.
- Support JEI/EMI ghost ingredient dragging.
