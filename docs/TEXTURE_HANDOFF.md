# Texture Handoff Checklist

For every texture Claude delivers to Grok:

- [ ] File name matches expected registry ID (e.g. `enrichment_chamber.png`)
- [ ] Exactly 16×16 pixels
- [ ] Original design (not an exact Mekanism copy)
- [ ] Tier color applied correctly where relevant
- [ ] Notes on any animated frames or special requirements
- [ ] GUI references or model expectations documented if non-standard
