# Texture Handoff Checklist

Claude produces all block (and recommended item) textures.

## Requirements

- Exactly **16×16 pixels**.
- Mekanism-inspired industrial style but **original designs** (no exact copies).
- Tier colors: Basic = green, Advanced = red, Elite = cyan, Ultimate = purple.

## Per-Texture Handoff Info

For every texture, provide:

- [ ] Filename (e.g. `enrichment_chamber.png`)
- [ ] Target path suggestion (e.g. `assets/mekanika/textures/block/`)
- [ ] Corresponding block or item ID
- [ ] Confirmation it is 16×16
- [ ] Animation frames (if any)
- [ ] Special notes (GUI, emissive, connected textures, etc.)

## Integration

Grok integrates the PNGs into the resource pack structure, blockstates, and models. Claude supplies the assets and this metadata.
