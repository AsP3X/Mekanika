# Side Configuration Screen

## Goals
- Dedicated full-screen or panel for configuring all faces and transmission types.
- Clear color language and mode cycling.

## Layout
- Unfolded or 3D face representation.
- Transmission type tabs or selector (Energy, Item, Fluid, Chemical, Heat).
- Mode legend with colors.
- Current configuration summary.
- Apply and reset buttons.

## Interaction
- Click faces to cycle modes.
- Shift-click for reverse cycle or specific modes.
- Works with Configurator in the world.
- Config cards can copy the full configuration.

## Integration
- Shared side configuration system.
- Triggers network rebuilds on change.
- Consistent with Configurator visual feedback.
