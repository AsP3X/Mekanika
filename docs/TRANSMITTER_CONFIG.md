# Transmitter Configuration

## Goals
- Configure connection modes, colors, and filters on cables and pipes.

## Features
- Connection type (Normal, Push, Pull, None).
- Color channels for item and chemical networks.
- Filter support on logistical transporters.
- In-world upgrading (alloy right-click).

## Interaction
- Configurator cycles modes on targeted face.
- Visual overlay when Configurator is held.
- Network Reader shows current configuration.

## Integration
- Side configuration system.
- Network rebuild on mode or color change.
- Debug tool reports connection status.
